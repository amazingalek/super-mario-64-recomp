The first release of Super Mario 64: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (*Super Mario 64 (U)*, a big-endian `.z64`, SHA-1 `9bef1128717f958171a4afac3ed78ee2bb4e86ce`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SuperMario64Recompiled-v0.1.0-windows-x64.zip` and run `SuperMario64Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SuperMario64Recompiled-v0.1.0-linux-x64.tar.gz` and run `SuperMario64Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** sound, EEPROM saves kept across restarts, and keyboard and gamepad input, at the game's 30 frames a second interpolated to the display's rate. The same recompiled game has been played from the file select through every star, the three Bowser fights and the credits on its web page.

**Enhancements**, each an option on the settings menu's Graphics tab with an Original value that runs the game as it shipped:

- High resolution at the window's size, with 2× MSAA
- Smooth motion at the display's refresh rate, with nothing smeared at camera cuts, warps or spawns
- Lower input lag
- Widescreen 3D and HUD
- Hi-res text, upscaled from your ROM (off by default)
- Higher model detail and draw distance
- Keyboard and gamepad controls, rebindable

**Not checked yet:** the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The [README](https://github.com/n64hub/super-mario-64-recomp#readme) has every setting and how to build it yourself.
